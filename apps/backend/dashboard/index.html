            כל השיחות

            איך זה עובד

            1. מפעילים הכל בפקודה אחת: npm run lab (מהתיקייה הראשית). היא מפעילה את שרת הכלים, את הבוט, ופותחת את הדף הזה.
            2. בוחרים ספק ותרחיש, קוראים מה להגיד, ולוחצים "התחל בדיקה".
            3. מדברים עם הבוט – מהדפדפן (מיקרופון) או מהטלפון. בזמן השיחה רואים מה הבוט עושה ומה נאמר.
            4. לוחצים "סיימתי", עונים על 1–2 שאלות ושומרים.
            5. חוזרים על זה ל-6 התרחישים (S1–S6). בלשונית התוצאות רואים מה עבר ומה ההחלטה.

            דפדפן או טלפון?

            דפדפן – הכי מהיר, בלי מספר ובלי עלות שיחה. מצוין לנסות ולכוונן. טלפון – קרוב יותר למציאות (איכות קו טלפון, רעש רחוב). מומלץ לעשות את ששת התרחישים ה"רשמיים" בטלפון, ובמיוחד את S4 מהרחוב.

            הגדרת טלפון ב-LiveKit (פעם אחת)

            1. Telephony → Phone Numbers → Rent a number, קידומת למשל 415 → Rent → Confirm.
            2. Telephony → Dispatch rules → Create new dispatch rule → JSON editor, להדביק ו-Create: 
              {
  "rule": { "dispatch_rule_individual": { "room_prefix": "call-" } },
  "name": "mishlav-c",
  "room_config": { "agents": [{ "agent_name": "mishlav-c" }] }
}
            3. ב-Phone Numbers: ⋮ ליד המספר → Assign dispatch rule → mishlav-c → Save.

            תקלות נפוצות

            מה קורהמה לבדוק
            "הבוט לא הצטרף" בדפדפןשהבוט רץ – בחלון של npm run lab צריכות להופיע שורות [bot]. שמפתחות LiveKit ו-Gemini מלאים ב-.env.
            הטלפון מצלצל ואין מענהשכלל הניתוב mishlav-c משויך למספר, ושהבוט רץ.
            הבוט מדבר אבל לא מופיעות פעולותששרת הכלים רץ (שורות [server]), ושהתחלת בדיקה לפני השיחה.
            לא שומעים את הבוטללחוץ "🔊 הפעל שמע", לבדוק עוצמה / אוזניות.
